cmd/main.go: Основной файл, который содержит функцию main и основной цикл программы.

internal/models/client.go: Содержит определение структуры Client и связанные с ней функции.

internal/models/part.go: Содержит определение структуры Part и связанные с ней функции.

internal/models/order.go: Содержит определение структуры Order и связанные с ней функции.

internal/handlers/client_handler.go: Содержит функции для обработки действий с клиентами (добавление, удаление, вывод).

internal/handlers/part_handler.go: Содержит функции для обработки действий с деталями (добавление, удаление, вывод).

internal/handlers/order_handler.go: Содержит функции для обработки действий с заказами (добавление, удаление, вывод).

internal/utils/validators.go: Содержит функции для валидации данных.

internal/db/db.go: Содержит функции для работы с базой данных (создание таблиц, очистка базы данных, заполнение шаблонными данными).





Папка /cmd
    Описание: Содержит основной исполняемый файл приложения.

    Файлы:

    main.go: Точка входа в приложение. Здесь находится функция main, которая инициализирует базу данных, создает таблицы и запускает основной цикл программы.

Папка /internal
    Описание: Содержит внутренние пакеты, которые не предназначены для использования вне проекта.



Папка /models
    Описание: Содержит определения структур данных, которые представляют сущности в вашем приложении.

    Файлы:

    client.go: Определяет структуру Client, которая представляет клиента в автосервисе.

    part.go: Определяет структуру Part, которая представляет деталь в автосервисе.

    order.go: Определяет структуру Order, которая представляет заказ в автосервисе.



Папка /handlers
    Описание: Содержит функции-обработчики для различных действий, которые пользователь может выполнять в приложении.

    Файлы:

    client_handler.go: Содержит функции для добавления, удаления и вывода информации о клиентах.

    part_handler.go: Содержит функции для добавления, удаления и вывода информации о деталях.

    order_handler.go: Содержит функции для добавления, удаления и вывода информации о заказах.



Папка /utils
    Описание: Содержит вспомогательные функции и утилиты, которые используются в различных частях приложения.

    Файлы:

    validators.go: Содержит функции для валидации данных, таких как имена, телефоны, цены и т.д.

    Папка /db
    Описание: Содержит функции для работы с базой данных, включая открытие соединения, создание таблиц, очистку базы данных и заполнение ее шаблонными данными.

    Файлы:

    db.go: Содержит функции для открытия соединения с базой данных, создания таблиц, очистки базы данных и заполнения ее шаблонными данными.

    Файл go.mod
    Описание: Файл, который управляет зависимостями проекта. Он содержит информацию о модуле, его версиях и зависимостях.
